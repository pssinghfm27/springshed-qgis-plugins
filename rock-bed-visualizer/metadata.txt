description=Project rock-bed planes from strike/dip observations using the Peepalkhola paper's method. Offline. No API keys. Works per-feature (batch) or single-bed.
about=Implements the math from "Visualizing Strikes and Dips of Rock Beds in QGIS with qgis2threejs" (CHIRAG / Dotiyalgaon). Given a rock observation point or a table of observations with strike, dip direction and dip amount, this plugin builds a regular point grid or a 3D polygon that represents the projected rock-bed plane through each origin. Outputs a z-attribute suitable for qgis2threejs and the native QGIS 3D map view. Entirely offline - no network, no API keys, no Claude, no tile servers.
